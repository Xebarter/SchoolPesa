# BUILD A COMPLETE WEB APP: SCHOOL PESA

Build a modern, production-quality web application called **School Pesa**.

School Pesa is an education fundraising and support platform that helps raise money to educate children and students from **nursery through university** and provide school requirements such as tuition, books, uniforms, shoes, meals, accommodation, technology and other educational needs.

The platform also shows donors the impact of their contributions through **stories, photos, videos, campaigns, statistics and reports**.

This should be a **real multi-page web application**, not just a landing page.

Build the public website and a complete admin dashboard.

---

# TECHNOLOGY

Use:

* Next.js
* React
* TypeScript
* Tailwind CSS
* shadcn/ui
* Lucide icons
* Supabase-ready architecture
* Next.js App Router

Use clean, reusable React components.

The application should be structured so Supabase can later be connected for:

* Authentication
* PostgreSQL database
* Storage
* User profiles
* Campaigns
* Donations
* Beneficiaries
* Stories
* Gallery
* Admin users

Do not create a fake backend architecture that would be difficult to connect to Supabase.

# CORE DESIGN DIRECTION

School Pesa should look:

**Bright. Human. Hopeful. Modern. Trustworthy. Premium. Fast.**

It should feel like a modern technology platform rather than a traditional NGO website.

Use:

* Bright backgrounds
* White space
* Strong typography
* Clean cards
* Beautiful photography
* Solid colors
* Subtle borders
* Soft shadows
* Rounded corners where appropriate
* Clear CTAs
* Modern dashboards
* Professional charts
* Excellent spacing

Avoid:

* Excessive gradients
* Excessive animations
* Glassmorphism everywhere
* Huge decorative elements
* Clutter
* Generic NGO templates
* Dark, gloomy interfaces
* Excessive shadows
* Slow visual effects

Do not use gradients as a major design element.

The interface should communicate:

**Education + Hope + Trust + Transparency + Impact**
